# ست‌داد

اپ جدا از مژدهی برای تعریف ست و تکرار هر حرکت، تیک زدن ست‌ها موقع تمرین، و سابقه جلسه.

## تفاوت با مژدهی

مژدهی تایمر حرکت و کار و استراحت است.
ست‌داد برای تعداد ست، تکرار، وزن، و ثبت انجام ست‌هاست — همان چیزی که مربی خواست.

## اجرا

پوشه را با صفحات گیت‌هاب یا هر میزبان ایستا باز کن.
داده فقط روی خود گوشی در حافظه محلی می‌ماند.
